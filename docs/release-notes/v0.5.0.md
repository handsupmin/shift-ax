# v0.5.0

- Adds a deterministic orchestration harness backed by local SQLite topic state.
- Routes execution through script-owned FSM transitions, DAG task readiness, priority queue claiming, retry scheduling, and idempotency keys.

- Updates execution orchestration so agents run only through registered executors after the harness claims a task.
