# v0.5.1

- objective request-to-commit 지표를 산출하는 `shift-ax eval`과 `npm run eval:objective`를 추가했다.
- objective eval report는 context retrieval, ambiguity scoring, token reduction, deterministic harness behavior, review gate accuracy, artifact completeness를 측정한다.
- eval 명령은 JSON/Markdown 리포트를 남기고, 어떤 지표든 threshold를 못 넘으면 non-zero로 실패한다.
