# Onboarding-Compliance Playbook

## Check
- `resolved-context.json` has been produced from the global Shift AX onboarding index.
- Every matched onboarding label or path is carried into `brainstorm.md`, `spec.md`, or `implementation-plan.md`.
- Rule-like onboarding lines such as required tests, conventions, architecture boundaries, or verification commands are reflected before implementation review.

## Approve when
- Matched context is visible in the reviewed artifacts.
- Extracted onboarding rules are represented in the plan/spec instead of remaining only in hidden conversation memory.

## Request changes when
- A matched context document disappears from the spec or plan.
- A required onboarding rule is not visible enough for a reviewer to hold the implementation accountable.
