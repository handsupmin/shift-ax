# PRD-Conformance Playbook

## Check
- Extract PRD requirements from the spec goal, constraints, brainstorm outcome, and implementation-plan acceptance criteria.
- Confirm each requirement has matching execution or changed-test evidence.
- Treat passing tests without requirement traceability as insufficient.

## Approve when
- Every extracted PRD requirement is backed by execution-result or test evidence.
- Acceptance criteria are specific enough to review and are not placeholders.

## Request changes when
- Any acceptance criterion lacks execution/test evidence.
- Implementation evidence exists, but it proves only generic activity rather than the reviewed behavior.
